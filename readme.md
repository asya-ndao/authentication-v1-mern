# Authentication v1 MERN Stack
Login/Register App with MERN Stack

This project is about creating an minimalistic authentication app with MERN Stack where user information are being saved in the database.

#### Technologies used:
- Client-side:
  - ReactJS / Vite
  - Bootstrap
  - Axios
- Server-side:
  - Express / Node JS
  - Mongoose
  - Cors
