# Authentication v1 MERN Stack
Login/Register App with MERN Stack

This project is about creating an minimalistic authentication app with MERN Stack where user information are being saved in the database.

#### Technologies used:
- Client-side:
  - ReactJS / Vite
  - Bootstrap
  - Axios
- Server-side:
  - Express / Node JS
  - Mongoose
  - Cors
 
#### How to run it

Run both server and client using `npm` command. However make sure to install packages in each folders before running start commands:

Move to the client folder
```
cd client
npm install
npm run start
```

then move to the server folder by opening a new terminal

```
cd server
npm install
npm start
```
